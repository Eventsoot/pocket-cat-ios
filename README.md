# Мурчик · Pocket Cat

Нативное приложение для iPhone на SwiftUI, iOS 17+. Собственный пиксельный котик, Dynamic Island, Live Activity на экране блокировки, интерактивные виджеты. Без сервера, рекламы и сторонних пакетов. Арт нарисован кодом; материалы Boko не использованы.

## Сборка без своего Mac

Подготовлен GitHub Actions workflow: **Actions → Build iPhone app → Run workflow**. Он собирает две неподписанные IPA на macOS runner. Для установки через Windows понадобится AltStore Classic и личная подпись бесплатным Apple ID; срок такой подписи — 7 дней. Начните с варианта basic. Полная версия с расширением требует отдельной проверки разрешений при подписи.

Подробные шаги и текущие ограничения: [INSTALL-WINDOWS.md](INSTALL-WINDOWS.md).

## Сборка на Mac

1. Установить Xcode и XcodeGen (`brew install xcodegen`).
2. В этой папке выполнить `xcodegen generate`.
3. Открыть `PocketCat.xcodeproj`, выбрать схему PocketCat.
4. В Signing & Capabilities у обоих targets выбрать свою Apple Developer Team. Заменить `com.example.PocketCat` на свой уникальный bundle ID в project.yml, а `group.com.example.PocketCat` — на зарегистрированную App Group и в project.yml, и в Shared/Pet.swift. Снова выполнить генерацию. Одна и та же App Group должна быть включена у приложения и расширения.
5. Выбрать iPhone с iOS 17+ и запустить. Для Dynamic Island нужен iPhone с этой функцией; на остальных будет Live Activity на экране блокировки.

Данные сохраняются локально в общей App Group. Если нужна установка на чужие телефоны, потребуется подписанная сборка через Apple Developer / TestFlight. На Windows нельзя собрать и подписать iOS-приложение через Xcode.

## Что работает в исходниках

- Домик с гуляющим котиком, реакцией на поглаживание, кормлением, игрой и сном.
- Сытость, радость и энергия уменьшаются по прошедшему времени, включая время вне приложения.
- Запуск и остановка Live Activity; compact, minimal, expanded Dynamic Island; кнопки кормления и игры в expanded presentation и на экране блокировки.
- Маленький и средний виджеты экрана «Домой», прямоугольный виджет экрана блокировки.
- App Intents обновляют общее состояние, виджеты и текущие Live Activities.

## Реальные ограничения iOS

Котик не может свободно перекрывать интерфейс других приложений. Он находится в отведённых iOS областях. Постоянный игровой цикл в фоне не используется. Непрерывное движение есть только в открытом приложении. В виджетах занятия меняются по timeline (запрошен шаг 15 минут, фактическое обновление определяет iOS). Dynamic Island показывает последнее состояние и обновляется от действий пользователя и при открытии приложения; спустя 15 минут без обновления показывает нейтральное «Котик ждёт тебя». Push-сервера нет. Анимации Live Activities ограничены системой. Live Activity завершается системой через ограниченное время (обычно максимум 8 часов активности); для новой сессии нужно снова открыть приложение. Это не постоянно работающий поверх iOS питомец.

## Проверка на Mac / iPhone

Исходники подготовлены на Windows; сборка Xcode и проверка на устройстве ещё не выполнены.

1. Собрать оба targets; проверить подпись и одинаковую App Group.
2. Покормить котика, закрыть приложение и открыть заново: сытость сохраняется.
3. Добавить small / medium / rectangular widgets. Кормление из виджета отражается в приложении.
4. Включить островок, свернуть приложение, раскрыть Dynamic Island и нажать «Играть». Проверить радость в приложении и виджете.
5. Заблокировать телефон, покормить котика из Live Activity. Проверить обновление состояния.
6. Выключить разрешение Live Activities в настройках: приложение объясняет ошибку.
7. Завершить Live Activity системным жестом, вернуться в приложение: кнопка снова предлагает запуск.
8. Проверить крупный текст, VoiceOver, тёмный режим и Always-On на реальном устройстве.
