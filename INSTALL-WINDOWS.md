# Бесплатная сборка и установка с Windows

## Статус

Обе IPA успешно скомпилированы в [GitHub Actions, запуск #1](https://github.com/Eventsoot/pocket-cat-ios/actions/runs/40570329877). Они предназначены для физического iPhone (arm64, iOS 17+). Подпись бесплатным Apple ID и запуск на телефоне ещё не проверены. ZIP с исходниками нельзя установить на iPhone как приложение.

## 1. Получить IPA без своего Mac

В отдельный репозиторий GitHub нужно отправить **содержимое только папки PocketCat**, чтобы `.github/workflows/build-ios.yml` находился в корне репозитория. Не отправляйте родительскую папку с другими проектами.

Откройте вкладку **Actions → Build iPhone app → Run workflow → Run workflow**. После завершения откройте запуск и скачайте один из Artifacts:

- **PocketCat-basic-unsigned** — простая версия, без App Groups и расширения. Это первая версия для проверки бесплатной установки. Котик живёт в приложении, уход и сохранение работают локально.
- **PocketCat-widgets-unsigned** — вариант с виджетами, Live Activity и Dynamic Island. Возможность подписать нужные разрешения бесплатным аккаунтом и корректную работу расширения нужно проверять отдельно на устройстве. Успешная компиляция этого не гарантирует.

Распакуйте скачанный архив: внутри будет файл `.ipa` и журнал сборки. Сборка не требует Apple ID, сертификатов, паролей или GitHub Secrets. IPA не подписана и напрямую через Safari не устанавливается.

Стандартные macOS runners бесплатны для открытых репозиториев. Для закрытых репозиториев действуют квоты аккаунта. Не включайте платные runners и не добавляйте платёжные данные ради этого проекта.

## 2. Установить через Windows

Следуйте официальной инструкции AltStore Classic: https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows

1. Установите Apple-компоненты и AltServer по официальной инструкции.
2. Подключите iPhone кабелем, разблокируйте и подтвердите доверие компьютеру.
3. Установите AltStore Classic через AltServer. Apple ID и пароль вводите лично в программе, не присылайте их в чат и не добавляйте в GitHub.
4. При необходимости включите Developer Mode по инструкции AltStore.
5. Передайте **PocketCat-basic-unsigned.ipa** на телефон, откройте AltStore → My Apps → **+** → выберите IPA. AltStore подписывает приложение вашей учётной записью.
6. После проверки basic можно отдельно попробовать вариант widgets. Эти варианты используют один bundle ID: установка другой версии может заменить предыдущую. Сохраняйте данные, если они важны.

При бесплатном аккаунте подпись действует **7 дней**. Для продления нужен AltServer на компьютере; автоматическое обновление зависит от соединения телефона с AltServer. Это не бессрочная установка по одной ссылке.

На телефоне девушки также нужны установка AltStore и подпись её Apple ID либо другой настроенный способ локальной установки. Отправка одной IPA не отменяет эти шаги.

## Если сборка не прошла

Откройте красный шаг в Actions и посмотрите ошибку. Журнал также сохраняется в Artifacts. Потребуется исправление проекта и новый запуск; наличие этого README не означает успешной компиляции.
